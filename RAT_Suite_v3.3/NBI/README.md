# National Bridge Inventory (NBI) Files

## Setup

Before running RAT Suite, download the NBI files:

**Double-click:** `download_nbi.bat`

The script automatically downloads:
- 2025AllRecordsDelimitedAllStates.txt (~150 MB)
- 2025NTI.xml (~5 MB)

Takes a few minutes. Do this once, then you're set!

## Manual Download

If the script doesn't work, download manually from:
- https://www.fhwa.dot.gov/bridge/nbi/
- https://www.fhwa.dot.gov/bridge/nti/

Save files to this folder: `v3.3/NBI/`
