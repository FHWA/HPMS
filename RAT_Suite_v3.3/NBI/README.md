NBI folder

The RAT Suite reads bridge and tunnel locations from the National Bridge
Inventory (NBI) and National Tunnel Inventory (NTI) files in this folder.
They label the bridge and tunnel spans found in the elevation data; the
suite runs without them.

To get the files, double-click download_nbi.bat. Set YEAR at the top of that
file to the release you want. The suite reads every .txt, .csv and .xml file
here, so keep only one year's files in this folder.
